# Property expenses

## Project Overview

This project displayes data on properties in differnt ways. It is built using Django, Pandas, and ChartJS. It reads data from a CSV file, which is Formatted in a predefined format, and generates bar and pie graphs.

## Technologies Used

- **Python** – Core programming language  
- **Django** – Web framework for building the application  
- **Pandas** – For data manipulation and analysis  
- **ChartJS** – For rendering charts and data visualisation in the browser  

## Prerequisites

- Python 3.10
- Node.js(version 14)

## What it Does

- Upload CSV files
- Data will be displayed in a table  
- Bar graphs and pie charts will be displayed using ChartJS.

## Setup Instructions

Follow these steps to get the project up and running locally:

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/data-analysis-web-app.git
cd data-analysis-web-app
```

### 2. Create and Activate a Virtual Environment

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Django Development Server

```bash
python manage.py runserver
```
